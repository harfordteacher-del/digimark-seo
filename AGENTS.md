# Panduan agen untuk repo ini

Repo ini digunakan untuk pekerjaan SEO dan digital marketing ditafebiyanpratiwi.com.

- Gunakan bahasa Indonesia untuk penjelasan, copy, dan laporan kecuali diminta lain.
- Baca `.agents/product-marketing.md` sebagai konteks brand.
- Gunakan skill yang relevan di `.agents/skills/`; baca `SKILL.md` dan referensi yang dibutuhkan sebelum mengerjakan tugasnya.
- File skill upstream adalah panduan. Validasi klaim teknis dan dukungan fitur yang dapat berubah terhadap sumber resmi terkini.
- Pisahkan fakta teramati, informasi pemilik, hipotesis, dan data yang belum tersedia. Cantumkan sumber, URL, serta tanggal untuk temuan audit.
- Utamakan alat gratis atau akun yang sudah tersedia. Jangan menganggap API berbayar telah tersedia.
- Jaga kompatibilitas WordPress dan Elementor Free. Periksa markup Yoast sebelum menambah schema atau metadata.
- Memasang skill tidak memberi akses ke website atau akun marketing. Kerjakan draf dan rekomendasi sesuai lingkup tugas; publikasi dan perubahan live memerlukan otorisasi pemilik.
- Jangan mengarang hasil kampanye, ranking, review, sertifikasi, alamat, jadwal, harga, atau volume keyword.
- Jangan menyimpan kredensial, data pelanggan, atau laporan privat di repo publik ini.
- Pertahankan isi vendored upstream. Untuk pembaruan, periksa diff dan perbarui `.agents/skills/SOURCES.json` serta lisensi bila diperlukan.
